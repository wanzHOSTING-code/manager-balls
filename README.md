# BRI Super League Manager

Prototype game football management berbasis HTML/CSS/JavaScript.

## Cara menjalankan
1. Extract ZIP.
2. Buka `index.html` di browser.
3. Pilih klub.
4. Atur taktik, lihat skuad, transfer pemain, dan simulasikan pertandingan.

## Teknologi
- HTML
- CSS
- Vanilla JavaScript
- LocalStorage
- Tanpa database / server

## Catatan
Ini adalah prototype offline. Data klub dan pemain berada di `app.js`. Save game disimpan di browser dengan LocalStorage.

Untuk pengembangan berikutnya dapat ditambah:
- Liga 2 dan sistem promosi/degradasi
- Piala Indonesia
- Kompetisi Asia
- Tim nasional
- AI transfer
- Cedera dan stamina
- Kontrak pemain
- Akademi
- Mesin simulasi pertandingan yang lebih detail
- Logo klub dan aset visual berlisensi
